"No GPU adapter" / does not start

WebGPU is switched off in the browser. In Chrome:

  1. Open chrome://settings/system
  2. Enable "Use graphics acceleration when available"
  3. Fully restart the browser

Still nothing? Update the GPU driver from NVIDIA/AMD/Intel - old drivers get blocklisted.

Two GPUs (laptop)

Browsers on Windows often land on the integrated GPU - fps barely improves.

  1. Windows Settings → System → Display → Graphics
  2. Add the browser → High performance
  3. Fully restart it

Check: the GPU line on the Status tab should show the discrete card.

Requirements

Desktop Chrome or Edge 121+, or Firefox 141+ on Windows, and a GPU from roughly 2016 or newer. Safari and phones - no.

How to use

Hover any video: the FG (on/off), picture and settings buttons appear on its left edge. Compare, an original/processed split view, is in the full settings.

What does not work

Netflix, Crunchyroll and other DRM sites - the browser never hands us their pixels, a platform limitation. On some sites the video may reload for a couple of seconds the first time you enable FG (CORS) - that is normal.
